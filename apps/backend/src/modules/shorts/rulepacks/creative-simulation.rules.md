# Creative Simulation Shorts

Use this rulepack when a user asks for an imagined matchup, hypothetical confrontation, what-if outcome, fictional scenario, versus comparison, power-scaling, or simulated sequence.

## Script

- Treat the video as a staged simulation, not factual reporting.
- Stay inside the sequence. Do not pause into a generic explanation.
- Move by beats: opening condition, first move, counter, failed contact, adaptation, escalation, decisive interaction, verdict.
- Every scene must change the fight state: distance, initiative, constraint, counter, escalation, damage, or verdict tension.
- Do not repeat the same "attacks, gets blocked, attacks again" beat across scenes.
- Narration describes what happens first, then gives only the minimum reason inside that action.
- Avoid absolute verdict lines like "끝입니다", "무조건 이깁니다", or "훨씬 유리합니다". Use interpretation-safe wording such as "상성상 유리해 보입니다" or "이 전제에서는 ... 쪽으로 기웁니다".
- Use `claimType: hypothetical` or `claimType: opinion` for imagined outcomes.
- `sourceRefs` can be empty for fictional simulation scenes.
- Preserve user-provided participants, starting conditions, abilities, and constraints.

## Image Prompts

- Each prompt should be a drawable action beat.
- Describe positions, distance, energy interaction, environment, emotion, and camera framing.
- Preserve named character references if the user provided them.
- Keep visual style neutral unless the user explicitly selected a style.
- Do not turn image prompts into a summary paragraph.
