# Eureka Flow — 소개 영상 제작 브리프 (다른 AI 핸드오프용)

> 이 문서를 다른 AI(또는 협업자)에게 통째로 주면 그대로 영상을 만들 수 있도록 쓴 정밀 브리프다.
> 한 줄 콘셉트: **"말 한마디가, 완성된 결과물이 된다."**

---

## 0. 다른 AI에게 줄 프롬프트 (이 문장으로 시작하라)

> "아래 브리프대로 **Remotion(React→MP4) 프로젝트 코드**를 작성해줘. 1920×1080 · 60fps · 60초(3600프레임).
> 6개 씬을 각각 React 컴포넌트로 만들고, 모든 모션은 `spring()` 또는 eased interpolation만 써(linear 금지).
> Apple 제품 광고처럼 극단적으로 미니멀하게. 한 컷에 메시지 하나, 여백 크게, 느리고 확신 있는 페이싱.
> 폰트는 Pretendard, 배경 `#0A0A0A`, 텍스트 `#F5F5F7`, 액센트 단 하나 `#3B82F6`(실행 글로우). 아래 스토리보드의 타이밍·텍스트·모션을 정확히 따라줘.
> 실제 영상 소재 2개(`assets/capture-graph.mp4`, `assets/result-shorts.mp4`)는 지정된 씬에 합성해줘."

## 2. 스타일 가이드 (엄수)

- **색:** 배경 `#0A0A0A`(거의 순흑) / 텍스트 `#F5F5F7` / 액센트 `#3B82F6` 단 하나(실행 단계 글로우에만). 컬러 남발 금지.
- **타이포:** Pretendard (한글). 큰 사이즈 + 넉넉한 자간/여백. 화면당 1~2줄.
- **모션 원칙:** linear 금지. 모든 등장/퇴장은 `spring` 또는 ease-in-out. 느리고 묵직하게. 빠른 컷·플래시 금지.
- **여백:** 화면의 60% 이상은 비워둔다. 요소는 중앙 정렬 또는 황금비 배치.
- **전환:** 크로스 디졸브 / 요소 모핑 중심. 와이프·슬라이드·회전 금지.

## 3. 스토리보드 (씬 6개, 60초)

### 씬 1 — 콜드 오픈 (0–8s)

- **화면:** 순흑. 중앙에 커서 깜빡임. 타이핑되듯 한 글자씩 등장: `"AI 반도체 트렌드로 쇼츠 하나 만들어줘"` (모노스페이스 → 등장 후 부드럽게 사라짐).
- **온스크린 텍스트(이어서):** `말하면, 됩니다.` (크게, 페이드 인)
- **모션:** 타이핑 4s → 문장 디졸브 → 태그라인 spring 등장.
- **사운드:** 정적 → 키 입력음 → 낮은 톤 한 번.

### 씬 2 — 과거의 방식 (8–16s)

- **화면:** 추상 노드 몇 개가 떠 있고, 손(또는 커서)이 **하나씩 수동으로 선을 연결**. 느리고 약간 번거롭게.
- **온스크린 텍스트:** `예전엔, 직접 연결해야 했죠.`
- **모션:** 노드들이 흐릿하게 페이드, 연결선이 더디게 그려짐 → 전체가 톤다운되며 뒤로 물러남.
- **의도:** 문제 제기. 짧고 추상적으로. 실제 앱 UI 보여주지 말 것.

### 씬 3 — ★매직 모먼트★ AI가 워크플로우 구성 (16–32s) [핵심]

- **화면:** 씬1의 문장이 중앙에 다시 떠오름. 거기서 **노드들이 스스로 조립**된다 — 하나씩 spring으로 등장하며 연결선이 그려짐.
- **노드 라벨 순서:** `자료수집 → 대본 → 장면구성 → 이미지 → 음성 → 영상합성 → 메타데이터`
- **온스크린 텍스트:** `이제, AI가 구성합니다.`
- **모션:** 노드 등장은 0.3s 간격 스태거. 연결선은 draw-on. 마지막에 전체 그래프가 살짝 줌아웃되며 안착. **여기서 페이싱을 가장 확신 있게(느리게) 잡아라.** 이 컷이 영상의 심장.
- **사운드:** 노드마다 미세한 틱 → 완성 시 부드러운 스웰.

### 씬 4 — 실행 (32–44s)

- **화면:** 완성된 그래프에 **액센트 컬러 글로우가 노드를 따라 흐른다**(실행 진행). 여기서 **실제 캡처 소재 `assets/capture-graph.mp4`를 깔끔한 프레임 안에 합성**(살짝 페이드/마스킹해서 어수선함 제거).
- **온스크린 텍스트:** `그리고, 실행.`
- **모션:** 글로우가 좌→우/위상순으로 흐름. 노드 완료 시 체크 느낌의 미세 펄스.

### 씬 5 — 결과물 (44–54s)

- **화면:** 그래프가 **폰 목업으로 모핑**. 폰 안에서 **실제 완성 쇼츠 `assets/result-shorts.mp4`(세로 9:16)가 재생**. 제목·자막·더빙이 보이게.
- **온스크린 텍스트:** `결과물까지, 자동으로.`
- **모션:** 그래프 → 폰 프레임으로 스무스 모핑. 폰은 중앙에 크게, 배경은 순흑.

### 씬 6 — 브랜드 클로즈 (54–60s)

- **화면:** 폰 페이드아웃 → 순흑. 중앙에 로고 **`Eureka Flow`** 등장.
- **태그라인:** `자연어로 만드는 자동화 워크플로우`
- **서브(작게):** `쇼츠 · 글 · 이미지 · 롱폼`
- **모션:** 로고 spring 등장 → 태그라인 페이드 → 전체가 천천히 페이드아웃(=씬1 순흑으로 루프 연결).
- **사운드:** 마무리 톤 한 번 → 정적.

## 5. 합격 기준 (이게 충족돼야 "완성")

1. 60초 정각, 끝→처음이 끊김 없이 루프된다.
2. 무음으로 재생해도 6개 메시지가 자막만으로 전달된다.
3. 씬3(노드 자가조립)이 한눈에 "AI가 워크플로우를 만들었다"로 읽힌다.
4. 실제 소재 2컷이 합성돼 "진짜 돌아간다"는 신뢰를 준다.
5. 컬러는 흑/백/액센트1 외에 없고, 모든 모션이 eased다(linear·플래시 없음).
6. 1920×1080 / 60fps MP4로 렌더된다.
