# Shorts Director

Shorts Director rules define how the Shorts should look.

- Use the same visual grammar for any topic.
- Canvas is vertical 9:16.
- Every image keeps one persistent top title.
- Prefer a black top title band with bold yellow/white Korean title text.
- The central scene should follow the selected image style and focus on the requested subject, action, and setting.
- Each scene has one short main caption.
- Use `[Image #1]` through `[Image #12]` or `[Image #15]`.
- The story should progress: hook -> setup -> escalation -> reveal -> takeaway -> CTA.
- GPT-image-2 may render short Korean text, but text must be short and bold.
- Do not put long paragraphs, dense tables, URLs, many numbers, or detailed dates inside images.
