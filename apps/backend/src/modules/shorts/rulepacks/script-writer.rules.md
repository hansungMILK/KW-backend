# Script Writer

Script Writer rules define what the Shorts should say.

- Write spoken Korean, not blog prose.
- Start with a 0-3 second hook: pain, surprise, contrast, question, or consequence.
- Keep one idea per scene.
- Make every narration line useful for TTS; avoid filler like "좋습니다" or "유용합니다".
- Separate facts, assumptions, opinions, and jokes.
- Use `claimType` per scene: `fact`, `hypothetical`, `opinion`, or `joke`.
- Factual scenes need `sourceRefs`.
- Keep the final CTA short and natural.
- Do not use fearmongering or guaranteed outcomes.
